# Порядок действий (QR)

Ниже описаны рабочие процессы для новых разделов меню: **Приёмка (QR)**, **Перемещение (QR)**, **Инвентаризация (QR)**.  
Во всех процессах **QR содержит только тип и UUID** (`ITM:{uuid}`, `BOX:{uuid}`), все связи — по `id`.

---

## Приёмка (QR)

1. Откройте **Приёмка (QR)** и выберите склад (локацию).
2. Нажмите **Создать** — создаётся документ приёмки.
3. Добавьте строку: **товар + количество** (базовая единица).  
   Дополнительно можно указать номер партии поставщика.
4. Нажмите **Сгенерировать** — создаются **партия (lot)** и **единицы товара (product_item)**.
5. Нажмите **Печать этикеток ITM** — распечатайте и наклейте QR на бутылки.
6. (Опционально) Сформируйте коробки:
   - Отсканируйте любую бутылку `ITM:...` для контекста (product/lot/location).
   - Нажмите **Создать коробку** (создаётся открытая коробка).
   - Сканируйте `ITM:...` и добавляйте товары в коробку.
   - Нажмите **Закрыть (seal)** и распечатайте QR коробки (**QR коробки**).
7. Нажмите **Подтвердить** — приёмка зафиксирована.  
   **Отменить** — погасит сгенерированные единицы (void).

---

## Перемещение (QR)

> Механика похожа на приёмку, **но партия не создаётся**.

1. Откройте **Перемещение (QR)** и создайте документ: **склад → бар**.
2. Нажмите **Сформировать список (FIFO)** — система подберёт товары по принципу «самые старые UUID».
3. При необходимости корректируйте список:
   - Можно **удалить** предложенные позиции из списка.
   - Можно **добавить** произвольные позиции, отсканировав `ITM:...`.
4. Переходите к отбору на складе и **сканируйте** товары:
   - Скан `ITM` → помечает товар как **in_transit**.
   - Скан `BOX` (sealed) → добавляет все товары коробки.
   - Если нужна частичная отгрузка из sealed коробки — она **автоматически открывается** и нужные товары выводятся из коробки.
5. Нажмите **Отгрузить**.
6. В баре сканируйте `ITM`/`BOX` для приёмки:
   - Статус → **in_stock**, локация → **bar**.
7. Нажмите **Закрыть**:
   - Все **непринятые** товары будут списаны как **lost_in_transit**.

---

## Инвентаризация (QR)

1. Откройте **Инвентаризация (QR)** и выберите локацию.
2. Нажмите **Создать**, затем **Старт** — система сформирует **ожидаемый список** всех товаров в локации.
3. Идите по складу и **сканируйте**:
   - `ITM` — конкретная бутылка.
   - `BOX` (sealed) — засчитывает все товары в коробке.
4. Нажмите **Закрыть**:
   - Все **не найденные** товары будут списаны как **lost** с причиной **missing_inventory**.
